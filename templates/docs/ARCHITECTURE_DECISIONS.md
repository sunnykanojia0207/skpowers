# Architecture Decisions

One entry per significant decision, newest first. Agents add an entry before changing architecture and never silently reverse an existing one.

## YYYY-MM-DD — Decision title
- **Context:** why a decision was needed
- **Decision:** what we chose
- **Alternatives:** what else we considered
- **Consequences:** trade-offs we accept, follow-ups
- **Status:** proposed / accepted / superseded by …
