# Code Style and Conventions

Keeps code written by different agents and people consistent. Prefer consistency with the existing code over novelty.

## 1. Principles
Readable over clever; small, focused functions and components; reuse existing components and utilities before writing new ones; no unnecessary abstractions or dependencies.
